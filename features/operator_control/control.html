en_to_ko puts English speech on screen in Korean. It needs a saved Gemini key; Whisper can only translate into English.

  
Audio input

  
The recording device Metagrafo listens to. Pick one, then Use this input. Capture switches in about a second, and this computer keeps the choice for the next time. OBS picks its own audio separately. Plugged a device in? Refresh list.

  
  
  
  
  

  
VAD pause

  
How long to wait after speech before cutting a caption. Allowed range 100–3000 ms. Applies live (no restart).

  
Guidelines: 250 ms snappy (may split on a breath) · 500 ms default · 1000 ms more pause. Below 200 ms usually cuts words; above 1500 ms feels hung.

  
  
  
  
Pauses per caption

  
1 translates on the first pause. 2 waits for a second pause, then prints each phrase on its own line. A stretch still cuts at 12 seconds. Applies live.

  
  
  
  
Previous text

  
On (default) gives Whisper the caption it just wrote when it translates the next phrase. Off translates each phrase alone. The vocabulary line stays in the prompt either way. Applies live.

  

    
    
  

  
Overlay

  
Keep the OBS Browser Source at 1920×1080. Right-click the source → Transform → Reset Transform so the type is not stretched. Do not drag the red handles or change source Height to crop captions — that squashes letters. Size the caption band here instead.

  
Position, font, box size, and insets apply live. Font is viewport width percent (vw), range 1.0–8.0. Box width 10–100 and height 5–100 are percent of the 1920×1080 overlay (default 100 × 30). Insets 0–20. After overlay HTML changes, right-click the source → Refresh once.

  
Font: 2.0 vw small · 2.5 vw default · 4.5 vw large. Box height 10 thin band · 30 default. If a line is sliced, raise box height, not OBS source height.

Gemini key

  
Paste the Gemini key you were given, then Save key. The words start coming from Gemini, and this computer keeps the key for the next time you open Metagrafo.

  
  
  
  
YouTube captions

  
Sends each finished line to YouTube as closed captions (the CC button). In YouTube Studio, open the stream's Stream settings, set latency to Normal, turn on Closed captions with POST captions to URL, and set the source language to the caption language (English, or Korean for en_to_ko). Copy the Captions Ingestion URL, paste it here, then Save URL. Sending starts at once, and this computer keeps the URL for the next time. YouTube refuses lines until the stream is live.

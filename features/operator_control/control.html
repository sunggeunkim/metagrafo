Booth control

Captions default ON. Turn OFF during worship so Whisper does not run on music.

VAD pause

How long to wait after speech before cutting a caption. Allowed range 100–3000 ms. Applies live (no restart).

Guidelines: 250 ms snappy (may split on a breath) · 400 ms default · 800 ms patient (fewer chopped sentences). Below 200 ms usually cuts words; above 1500 ms feels hung.

Overlay

Position and font size apply live to OBS. Font size is viewport width percent (vw). Both caption lines use the same size. Allowed range 1.0–8.0 vw.

Guidelines: 2.4 vw small · 3.2 vw default · 4.5 vw large for the projector. Below 2 vw is hard to read in the sanctuary; above 6 vw crowds the frame.

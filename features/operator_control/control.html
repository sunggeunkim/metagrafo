Booth control

Captions default ON. Turn OFF during worship so Whisper does not run on music.

VAD pause

How long to wait after speech before cutting a caption. Allowed range 100–3000 ms. Applies live (no restart).

Guidelines: 250 ms snappy (may split on a breath) · 500 ms default · 1000 ms more pause. Below 200 ms usually cuts words; above 1500 ms feels hung.

Overlay

Keep the OBS Browser Source at 1920×1080. Right-click the source → Transform → Reset Transform so the type is not stretched. Do not drag the red handles or change source Height to crop captions — that squashes letters. Size the caption band here instead.

Position, font, box size, and insets apply live. Font is viewport width percent (vw), range 1.0–8.0. Box width 10–100 and height 5–100 are percent of the 1920×1080 overlay (default 100 × 30). Insets 0–20. After overlay HTML changes, right-click the source → Refresh once.

Font: 2.0 vw small · 2.5 vw default · 4.5 vw large. Box height 10 thin band · 30 default. If a line is sliced, raise box height, not OBS source height.
